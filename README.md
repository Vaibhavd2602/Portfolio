# Vaibhav Dubey Portfolio

Static portfolio built from the uploaded resume and inspired by the provided reference portfolio.

## Included

- `index.html` - main single-page portfolio
- `styles.css` - responsive dark portfolio styling
- `script.js` - mobile nav, tabs, active links, reveal animations, and contact mailto behavior
- `assets/hero-visual.png` - local hero image
- `assets/Vaibhav-Dubey-Resume.pdf` - uploaded resume used by the Download Resume button

## Resume-Based Content

The page includes:

- AI and Python-focused profile summary
- Education details
- Core skills
- Certifications
- Achievements
- Academic projects
- GitHub, LinkedIn, LeetCode, email, and phone contact details

Open `index.html` in a browser to view the portfolio.
